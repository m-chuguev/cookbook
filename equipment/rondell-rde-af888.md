# Аэрогриль Rondell RDE-AF888

Мой основной аэрогриль для домашних рецептов.

## Основное
- Чаша: 6,5 л
- Максимальная температура: до 230 °C
- Есть термощуп для контроля внутренней температуры мяса и птицы
- Термощуп может автоматически завершать приготовление при достижении заданной температуры
- Есть ручные и предустановленные программы

## Шпаргалка по термощупу
Щуп вставлять в самую толстую мясистую часть продукта. Кончик не должен касаться кости.

Для куриных голеней удобно ориентироваться примерно на 78–80 °C внутри. Для хрустящей корочки при необходимости после достижения температуры можно дать несколько минут на высокой температуре, следя за цветом.
